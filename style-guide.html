Design decisions

Typography over boxes

Earlier drafts of this site used cards, tags, and tinted panels to create structure. This version uses rules, italics, and scale instead — the way a magazine does. Fewer containers, more hierarchy.

Legibility as a requirement, not a preference

Body text is 17px, nothing is set below 13px, and every color pair was checked against WCAG before it entered the palette. The contrast table above is generated from the actual token values.

Tags as section markers

Project tags are square-ruled markers in Franklin — the way a paper marks its sections — rather than rounded, tinted pills. Same scannability, different lineage.
